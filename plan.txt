1. Project Overview

This project aims to build a web-based platform that converts YouTube videos and playlists into downloadable PDF slides by extracting unique frames automatically.

The system will:

Accept YouTube video or playlist URLs

Download and process the videos

Extract important frames using similarity detection

Generate a structured PDF

Provide download access to users

The platform will be fully automated from input to PDF generation.

2. Objectives

Build a fully automated backend processing system

Provide a clean and simple frontend interface

Make the website SEO-friendly

Allow scalable future upgrades

4. Core Features (MVP)
4.1 Input Handling

Accept single YouTube video URL

Accept YouTube playlist URL

Validate input before processing

4.2 Video Processing

Detect whether URL is video or playlist

Extract video ID

Download video using yt-dlp

Restrict maximum video duration (e.g., 15–20 minutes)

4.3 Frame Extraction

Read video using OpenCV

Compare frames using SSIM

Save only unique frames

Maintain timestamp for each frame

4.4 PDF Generation

Convert frames to landscape PDF

Add timestamp on each slide

Auto-adjust text color for visibility

4.5 Output

Generate downloadable PDF

Delete temporary files after completion
